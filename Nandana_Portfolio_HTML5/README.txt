NANDANA - HTML5 PORTFOLIO

Files:
- index.html    : Home Page
- about.html    : About Me
- gallery.html  : My Gallery
- contact.html  : Contact Me
- signup.html   : Registration/Signup Page
- css/style.css : Styling and animations
- js/script.js  : Small interactions
- images/       : Sample SVG images

HOW TO RUN:
1. Extract the ZIP file.
2. Open the portfolio folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Replace the sample SVG images with your own JPG/PNG photos if desired.
5. Change the sample email/phone/social details in contact.html before submission.

The signup form intentionally has no custom validation, as the assignment says validation is not required.
